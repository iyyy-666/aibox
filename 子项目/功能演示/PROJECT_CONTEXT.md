# 功能演示 - Project Context

更新时间：2026-09-21

## 作用

这是人工智能试验箱的统一学生端软件。它以单一窗口展示 13 个现有演示功能，并统一管理启动、停止和资源释放。

## 技术边界

- 统一外壳使用 FastAPI、PyWebView 和原生 HTML/CSS/JavaScript。
- 各功能继续复用对应子项目中的识别算法、模型和硬件控制逻辑。
- 首页不得占用摄像头、麦克风、机械臂或云台。
- 同一时间只能运行一个功能模块。
- 摄像头画面和云台控制不是独立模块。

## 维护规则

- 修改功能适配器前先阅读对应子项目的 `PROJECT_CONTEXT.md`。
- 不在本目录复制模型文件；模型继续使用设备上的既有路径。
- 退出功能必须以服务端资源释放验证结果为准。
- 设备部署前必须保留可恢复备份。
