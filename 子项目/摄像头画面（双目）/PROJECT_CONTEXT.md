# 摄像头画面（双目） - Project Context

更新时间：2026-08-30

## 1. 项目名称

摄像头画面（双目）

## 2. 项目位置

G:\codexwork\人工智能实验箱\子项目\摄像头画面（双目）

## 3. 项目目的

显示双目摄像头合成后的正常画面，用于观察摄像头状态和后续视觉实验。

## 4. 当前入口文件

代码/camera_view_app.py；启动脚本/camera_view.sh

## 5. 使用技术栈

Python, Tkinter, OpenCV, V4L2

## 6. 当前完成状态

可用，需避免和其它视觉软件同时占用摄像头。

## 7. 已知 bug / 待优化点

历史上出现过黑白、卡顿、关不掉重复打开；关闭后不得后台占用摄像头。

## 8. 依赖关系

硬件：双目摄像头。

## 9. 维护规则

- 修改本软件前先读本文件。
- 代码目录保存从 RK3588 最新运行环境拉取的业务文件副本。
- 启动脚本目录保存 /usr/local/bin 中对应脚本。
- 桌面入口目录保存 /home/ztl/Desktop 中对应 .desktop 文件。
- 公共模块优先查看 子项目/共享模块与资源。
- 涉及硬件的软件，测试前先确认对应麦克风、声卡、摄像头、串口或机械臂已连接。
