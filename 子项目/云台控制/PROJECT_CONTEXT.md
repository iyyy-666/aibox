# 云台控制 - Project Context

更新时间：2026-08-30

## 1. 项目名称

云台控制

## 2. 项目位置

G:\codexwork\人工智能实验箱\子项目\云台控制

## 3. 项目目的

通过 RK3588 软件控制 STM32，再由 STM32 控制二维云台两个舵机微调旋转。

## 4. 当前入口文件

代码/gimbal_control_app.py；启动脚本/gimbal_control.sh

## 5. 使用技术栈

Python, Tkinter, 串口, STM32 固件, 舵机 PWM

## 6. 当前完成状态

进行中；软件与固件/串口/接线需要继续闭环验证。

## 7. 已知 bug / 待优化点

历史上出现软件显示连接但云台不动；需区分 3588 软件、STM32 固件、串口和供电问题。

## 8. 依赖关系

硬件：STM32F407VET6、二维云台、LDX227、LD3015MG。

## 9. 维护规则

- 修改本软件前先读本文件。
- 代码目录保存从 RK3588 最新运行环境拉取的业务文件副本。
- 启动脚本目录保存 /usr/local/bin 中对应脚本。
- 桌面入口目录保存 /home/ztl/Desktop 中对应 .desktop 文件。
- 公共模块优先查看 子项目/共享模块与资源。
- 涉及硬件的软件，测试前先确认对应麦克风、声卡、摄像头、串口或机械臂已连接。
