# RK3588 手掌追踪设计

## 目标

新增独立桌面软件“手掌追踪”。应用从 RK3588 的双目摄像头 `/dev/video41` 读取画面，在主界面显示左目实时视频、中心准星和手掌框。用户先将一个手掌置于画面中央，再点击“开始追踪”；此后云台通过小幅 PWM 调整，使锁定手掌的框中心保持在画面中心附近。

## 运行基线与硬件

- 应用目录：`/root/robot_arm`。
- 摄像头：双目 USB 摄像头 `/dev/video41`，输入为 1280x480 MJPG，左目为 640x480。
- 手掌检测：复用 `hand_landmarks.py` 的 MediaPipe 检测，失败时保留 `palm_recognition_app.py` 的轮廓检测兜底。
- 云台控制板：`/dev/serial/by-id/usb-1a86_USB_Single_Serial_5C67040336-if00`，115200 baud，已验证 ACK。
- 云台协议：ASCII PWM 命令，`#<id>P<pwm>T<ms>!`。
- 舵机：水平轴 ID 1，俯仰轴 ID 2；安全 PWM 范围 500-2500，中心值 1500。
- 云台启动参数与端口优先级沿用 `/usr/local/bin/gimbal_control.sh`。

## 交互

1. 打开应用后显示摄像头左目实时画面、中心准星、状态提示“请将手掌放在画面中央”和禁用的“开始追踪”按钮。
2. 当一个可用手掌框进入中心启动区域后，按钮启用。点击时锁定该手掌的跟踪器 ID，并将按钮文字改为“停止追踪”。
3. 追踪时持续显示手掌框、中心偏移、追踪状态及简明云台状态。画面保持为主区域，不以文字替代视频。
4. 点击“停止追踪”、关闭窗口、摄像头错误或云台通信错误时，立即停止后续舵机指令；不自动回中。
5. 连续 0.5 秒无有效手掌时，停止舵机指令并显示“未检测到手掌”。追踪开关保持开启，锁定目标重新可见后自动恢复。

## 检测与目标锁定

- 从双目帧拆分左目和右目；主界面与控制均使用左目坐标。
- 使用 MediaPipe 手掌框为主、轮廓检测为兜底；维持现有单手上限。
- 点击开始时选择启动区域中最接近画面中心的框；之后使用 IoU 和中心距离关联，拒绝其他手掌抢占目标。
- 检测结果需经过短时稳定过滤。仅有效手掌框可以驱动云台；低置信或失配结果只更新显示状态。

## 云台闭环

- 控制器按固定节奏读取最新锁定框中心，而不是每一帧直接发送串口指令。
- 将归一化横向和纵向偏移分别映射到水平和俯仰轴。每次仅向有明显偏移的轴发送小幅 PWM 更新。
- 中心死区：偏移在阈值内时不发送命令，消除中心附近的往复抖动。
- 采用平滑后的比例 PWM 微调：偏移越大，PWM 步进越大；接近中心时自动降低步进。该方案不使用积分或微分项，以适应普通舵机与视觉延迟。
- 最大命令速率通过 PWM/角度标定值换算，并限制为约 20 度/秒。控制器还限制每次命令的最小间隔和最大 PWM 步进。
- PWM 始终裁剪至 500-2500。初次物理调试提供仅小幅移动的轴向校验，并以环境变量保存水平、俯仰的方向反转和标定比例。
- 发送每条命令后必须接收现有控制板 ACK；无 ACK 或串口异常时停止追踪动作并显示错误。

## 模块与部署文件

- `palm_tracking_control.py`：无 GUI 的目标锁定、偏移滤波、死区、比例步进、速率限制、丢失超时和串口云台客户端。
- `palm_tracking_app.py`：Tkinter 应用，负责摄像头、检测线程、视频绘制、按钮状态和控制器调用。
- `palm_tracking.sh`：单实例启动器，导出摄像头、检测、串口、舵机标定和控制参数，使用独立锁文件。
- `palm_tracking.desktop`：桌面入口，名称为“手掌追踪”，图标风格复用现有 AIBOX 图标目录。
- `assets/icons/palm_tracking.svg`：与现有深色桌面图标风格一致的手掌追踪图标。

## 错误处理

- 摄像头打开或读帧失败时停止控制命令并按现有视觉程序方式重试。
- 手掌丢失、检测器降级、串口断开、ACK 超时、退出窗口均不会发送额外的云台运动指令。
- 云台达到软件 PWM 限位时保持限位值，并在状态区提示，避免连续冲击机械结构。
- 同一时间只允许一个使用 `/dev/video41` 的视觉 GUI 运行。

## 测试与验收

- 单元测试：启动区域判断、目标锁定、偏移死区、比例 PWM 步进、20 度/秒速率限制、PWM 限位、丢失 0.5 秒停止、串口 ACK 失败处理和轴向反转。
- 本机测试：模块导入、命令帧格式和 Tkinter 依赖的无窗口逻辑测试。
- 板端测试：Python 语法检查、串口连接与 ACK 验证、摄像头打开和实时画面显示、按钮状态、停止/退出的无额外命令验证。
- 物理验收：在用户观察下执行小幅轴向校验；确认手掌在画面四个方向偏移时云台向正确方向、速度不超过约 20 度/秒、中心附近不明显抖动、手掌离开 0.5 秒后停止且回到画面后可续追。

## 非目标

- 不改变既有“手掌识别”应用的手势识别行为。
- 不控制机械臂或其他舵机。
- 首版不支持同时跟踪多只手，也不自动回中。
