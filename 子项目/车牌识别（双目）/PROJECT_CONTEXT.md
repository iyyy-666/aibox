# 车牌识别（双目） - Project Context

更新时间：2026-08-30

## 1. 项目名称

车牌识别（双目）

## 2. 项目位置

G:\codexwork\人工智能实验箱\子项目\车牌识别（双目）

## 3. 项目目的

识别二维车牌图片，区分绿牌/蓝牌并在右侧显示车牌文本和车辆类型。

## 4. 当前入口文件

代码/plate_recognition_app.py；启动脚本/plate_recognition.sh

## 5. 使用技术栈

Python, Tkinter, OpenCV, YOLO/图像处理/OCR

## 6. 当前完成状态

可用但 OCR 和检测精度需按实际图片继续调。

## 7. 已知 bug / 待优化点

倾斜、反光、尺寸过小会影响识别。

## 8. 依赖关系

共享：vision_targeting.py。硬件：双目摄像头。

## 9. 维护规则

- 修改本软件前先读本文件。
- 代码目录保存从 RK3588 最新运行环境拉取的业务文件副本。
- 启动脚本目录保存 /usr/local/bin 中对应脚本。
- 桌面入口目录保存 /home/ztl/Desktop 中对应 .desktop 文件。
- 公共模块优先查看 子项目/共享模块与资源。
- 涉及硬件的软件，测试前先确认对应麦克风、声卡、摄像头、串口或机械臂已连接。
