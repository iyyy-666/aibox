# 水果识别（双目） - Project Context

更新时间：2026-08-30

## 1. 项目名称

水果识别（双目）

## 2. 项目位置

G:\codexwork\人工智能实验箱\子项目\水果识别（双目）

## 3. 项目目的

在双目合成画面中识别常见水果或二维水果图片，并在侧边显示中文名称。

## 4. 当前入口文件

代码/fruit_recognition_app.py；启动脚本/fruit_recognition.sh

## 5. 使用技术栈

Python, Tkinter, OpenCV, Ultralytics YOLOv8n/分类模型

## 6. 当前完成状态

可用但对二维图片和特定水果仍可能漏检。

## 7. 已知 bug / 待优化点

水果专用权重不足时识别精度有限；背景误检需继续优化。

## 8. 依赖关系

共享：vision_targeting.py。模型见 model_manifest.txt。硬件：双目摄像头。

## 9. 维护规则

- 桌面入口目录保存 /home/ztl/Desktop 中对应 .desktop 文件。
