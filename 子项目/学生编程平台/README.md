# AIBox Studio 学生编程平台

面向 RK3588 人工智能实验箱的本地离线学生编程教学软件。

本目录保存产品设计基线和第一阶段可运行原型。设计依据为
`AI智能试验箱应用实训教程_完整版.docx` 中的 56 个基础实验。

## 当前实现

- PySide6 四区学生工作台：课程导航、Python 编辑器、实验效果、运行结果。
- 8 篇 16 章 56 个内置实验，以及可保存和恢复的代码模板。
- 独立 Python 子进程运行、AST 权限校验、超时和主动停止。
- 模拟 `aibox` SDK：机械臂、摄像头、视觉、人脸、手势、语音、AI 和雷达。
- 机械臂 PWM `800–2200` 双边界设计；当前原型已在模拟 SDK 中强制执行。

当前版本是模拟设备开发版，不会连接或占用真实摄像头、机械臂、雷达和声卡。
当前 AST 校验用于教学提示，独立子进程用于故障隔离，但 Windows 开发版还不是
可运行不可信代码的安全沙箱。部署到 RK3588 前必须完成 `bubblewrap`、无网络命名
空间、cgroup/资源上限、进程组清理和 Device Service 会话鉴权，不能只依赖 AST。

## 本地启动

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e . pytest
.\.venv\Scripts\aibox-studio.exe
```

运行测试：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

## 已确认的产品约束

- 一台实验箱对应一名学生，本机离线运行。
- 第一版只提供学生端，不做账号、教师端、成绩和自动判题。
- 学生只学习 Python 基础和 `aibox`，不接触设备通信与系统管理。
- 软件预装到 RK3588 的 `ztl` 桌面，与“功能演示”并列使用。
- 教材约 90% 定稿；后续微调通过版本化课程包完成。
- 机械臂课程复用功能演示的预设动作、夹爪动作和 6 舵机微调，PWM 固定限制为 `800–2200`。
- 语音控制只支持功能演示现有命令；文字朗读通过离线 TTS 和实验箱声卡输出。
- 摄像头只教学调用实时画面；第一版不提供通用物体目标检测实验。
