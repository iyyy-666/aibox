# AIBox Studio 课程包数据格式

版本：0.1（设计草案）  
日期：2026-10-08

## 1. 目标与边界

课程包是教材内容与软件运行行为之间的版本化合同。它负责描述课程导航、实验说明、代码模板、允许的学生能力和效果面板，不包含驱动、模型、可执行文件或任意脚本。

第一版课程包由厂家制作并随软件离线安装，不提供教师端编辑器。课程包更新不得覆盖学生已保存的代码。

## 2. 包目录

```text
course-basic-ai-1.0.0/
├── manifest.json
├── experiments.json
├── lessons/
│   ├── intro.box.01.md
│   └── ...
├── templates/
│   ├── intro.box.01.py
│   └── ...
└── checksums.json
```

- `manifest.json`：课程身份、版本和兼容范围。
- `experiments.json`：篇、章、实验及运行策略。
- `lessons/`：学生可见的实验目的、步骤和提示，使用受限 Markdown。
- `templates/`：只读 Python 初始模板。
- `checksums.json`：除自身外所有文件的 SHA-256，用于离线完整性检查。

包内路径必须是 UTF-8 相对路径，不允许 `..`、绝对路径、符号链接和隐藏文件。单个课程包解压后建议不超过 50 MiB；模型放在 `/opt/aibox-models/`，不进入课程包。

## 3. manifest.json

```json
{
  "schema_version": "1.0",
  "course_id": "cn.aibox.basic-ai",
  "course_version": "1.0.0-rc1",
  "title": "人工智能实验箱应用实训",
  "language": "zh-CN",
  "sdk_compatibility": ">=1.0,<2.0",
  "studio_compatibility": ">=1.0,<2.0",
  "experiment_count": 56,
  "entry": "experiments.json",
  "published_at": "2026-10-08",
  "publisher": "AIBox",
  "content_revision": "textbook-2026-10-08"
}
```

约束：

- `schema_version` 决定解析规则；不支持的主版本必须拒绝安装。
- `course_id` 发布后不可变；标题调整不改变身份。
- `course_version` 使用语义化版本。文字勘误升补丁版，兼容性内容增加升次版本，破坏实验 ID 或教学合同才升主版本。
- `experiment_count` 必须与实际启用实验数一致，当前基线固定为 56。
- 兼容范围在安装和启动时均校验，不允许“带警告继续运行”。

## 4. experiments.json

顶层结构：

```json
{
  "parts": [
    {
      "id": "vision",
      "title": "第二篇 AI视觉实验",
      "order": 2,
      "chapters": [
        {
          "id": "vision.color",
          "title": "第二章 颜色识别",
          "order": 2,
          "experiments": [
            {
              "id": "vision.color.01",
              "number": 4,
              "title": "体验颜色识别",
              "lesson": "lessons/vision.color.01.md",
              "template": "templates/vision.color.01.py",
              "allowed_imports": ["aibox", "time"],
              "capabilities": ["vision.color"],
              "resources": ["camera", "npu"],
              "panel": "camera",
              "run_mode": "oneshot",
              "timeout_seconds": 60,
              "output_limit_bytes": 65536
            }
          ]
        }
      ]
    }
  ]
}
```

### 4.1 稳定身份

- `part.id`、`chapter.id` 和 `experiment.id` 在首次发布后保持稳定。
- `number` 对应教材编号 1 至 56，必须唯一且连续。
- 标题、说明和模板可随兼容版本修改，但不能借标题变化重用旧 ID。
- 删除实验时保留迁移记录，不能把原 ID 分配给新实验。

### 4.2 权限字段

| 字段 | 作用 | 校验规则 |
|---|---|---|
| `allowed_imports` | 此实验可导入的模块 | 必须是平台总白名单的子集 |
| `capabilities` | 可调用的 aibox 方法 | 使用小写 `类.方法`，必须存在于 SDK 注册表 |
| `resources` | 运行前原子申请的设备资源 | 必须覆盖所有能力依赖，不允许模板临时越权 |
| `panel` | 右侧效果面板 | `text/camera/radar/arm/voice/assistant` |
| `run_mode` | 生命周期 | `oneshot` 或 `observe` |
| `timeout_seconds` | 顶层代码执行上限 | 1 至 300；观察状态不计入该时限 |
| `output_limit_bytes` | 标准输出总量 | 1024 至 262144 |

权限取交集，不取并集：平台总白名单、课程包声明和当前实验能力三者均允许，调用才可执行。

### 4.3 运行模式

- `oneshot`：顶层代码结束且没有持续任务后，释放资源并返回空闲状态。
- `observe`：顶层代码结束后允许已声明的持续效果继续运行，界面进入“观察中”；点击停止、切换实验或关闭软件时统一清理。
- 课程包不能自定义停止逻辑。停止与资源释放由 Runner 和 Device Service 保证。

## 5. 说明文本与模板

课程说明仅允许标题、段落、列表、行内代码和代码块；不允许 HTML、远程图片、外部链接、脚本和嵌入对象。所有内容必须离线可用。

模板要求：

1. 编码为 UTF-8，扩展名为 `.py`。
2. 通过 Python 语法检查和 Runner AST 规则。
3. 仅导入 `allowed_imports` 中的模块。
4. 仅调用 `capabilities` 中声明的公开 API。
5. 不包含硬件路径、串口参数、模型路径或系统命令。
6. 默认可直接运行；教材待确认的实验可以标记 `draft`，但正式发布包中不得启用未确认模板。

机械臂模板只能使用 SDK 白名单动作。若实验允许 `arm.servo`，课程清单必须额外
声明高级机械臂能力；1 至 6 号舵机和 `800–2200` PWM 范围仍由 SDK 与 Device
Service 强制校验，不能由课程包扩大。

## 6. 学生代码保存与升级

学生文件按实验稳定 ID 保存：

```text
/home/ztl/Documents/AIBoxStudio/
└── cn.aibox.basic-ai/
    ├── workspace.json
    └── experiments/
        └── vision.color.01.py
```

`workspace.json` 记录学生代码来源课程版本、模板哈希和最后保存时间。课程升级时：

1. 新模板安装到只读课程目录。
2. 已保存学生代码保持不变。
3. 若模板发生变化，界面提示“教材模板已更新”，提供查看新模板和恢复模板操作。
4. 恢复模板前生成本地备份，不静默覆盖。
5. SDK 主版本不兼容时禁止运行并提示升级软件，不自动改写学生代码。

## 7. 安装与校验流程

```text
选择离线课程包
  -> 在临时目录解包
  -> 校验路径和大小
  -> 校验 checksums.json
  -> 校验 JSON 结构与版本兼容性
  -> 校验 56 个编号、ID、模板和能力
  -> 模拟设备模式试运行模板
  -> 原子切换当前课程版本
  -> 保留上一可用版本用于回滚
```

任何一步失败都不得改变当前课程。正式交付包应增加厂家离线数字签名；`checksums.json` 只能发现损坏，不能单独证明来源可信。

## 8. 发布验收

- 所有 JSON 可通过固定 Schema 校验，未知必填字段和重复 ID 会被拒绝。
- 1 至 56 编号各出现一次，`experiment_count` 为 56。
- 每个引用文件存在且哈希一致，不存在包外路径。
- 所有模板在模拟设备模式下通过语法、安全和能力检查。
- 断网环境可加载全部说明、模板和资源。
- 从上一课程版本升级不会覆盖任何学生文件。
- 安装中断后仍能启动上一可用课程版本。
