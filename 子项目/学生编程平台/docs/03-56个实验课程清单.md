# 56个实验课程清单

版本：0.1  
来源：`AI智能试验箱应用实训教程_完整版.docx`

## 1. 清单字段

正式课程包中，每个实验至少包含：

| 字段 | 含义 |
|---|---|
| `id` | 永久稳定的实验ID |
| `number` | 教材实验编号 |
| `part/chapter/title` | 教材导航文本 |
| `template` | 只读初始代码模板 |
| `allowed_imports` | 此实验允许导入的模块 |
| `capabilities` | 允许调用的 `aibox` 能力 |
| `panel` | 右侧效果面板 |
| `run_mode` | `oneshot` 或 `observe` |
| `timeout` | 单次代码执行上限 |
| `sdk` | 兼容的 SDK 版本范围 |

## 11. 课程包验收规则

每次教材或课程包更新必须自动验证：

1. 56 个编号和稳定 ID 唯一且完整。
2. 每个模板能够通过 AST 安全检查。
3. 每个模板只调用清单声明的 API。
4. 模拟设备模式下 56 个模板全部可运行。
5. 模板使用的 API 与声明的 SDK 版本兼容。
6. 面板类型与能力一致，例如视觉实验不能配置为纯文本面板。
7. 所有学生可见文本为中文，且不包含设备路径和底层协议。
