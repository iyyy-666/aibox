# 语音增量优化（本地软件验证）

日期：2026-10-20。本文仅记录本次本地代码与合成负载验证，不代表真实录音识别率或板端速度。

## 实际调用链与边界

| 模式 | 统一入口调用链 | 语法/模型生命周期 |
| --- | --- | --- |
| 儿歌 | runtime → VoiceWorker(nursery_rhyme) | 自由识别、原有歌名匹配；本次增加同一 worker 的模型复用 |
| 机械臂语音 | runtime → VoiceWorker(voice_robot_arm) | 原有 ROBOT_COMMANDS 与 Vosk 命令语法；独立 worker 模型 |
| AI 对话 | runtime → AssistantWorker → VoiceWorker(ai_assistant) | 自由识别；LLM/TTS 既有懒加载保留，LLM 并发串行化 |
| 语音搬运 | transport_runtime → VoiceWorker(ai_assistant) → 原有 CachedEngineFactory | 保留既有 ASR 缓存、搬运状态机与单次动作保护；共用监听异常修复 |

ASR 工厂 `_legacy_engine_factory()` 从 `AIBOX_LEGACY_ROOT`（默认 `/root/robot_arm`）导入 `voice_engine.VoiceEngine`。当前实际软件的本地基线是 `子项目/功能演示/代码/voice_engine.py`，不是其它子项目的同名历史副本。共享模块、儿歌、AI 助手、语音机械臂四份历史副本均与此文件 SHA256 不同，本次没有覆盖它们。

活动引擎包含 Paraformer、SenseVoice、Sherpa、Vosk、Whisper 后端及原有回退逻辑。统一环境默认 SenseVoice；实际生效后端仍须由板端环境与模型可用性验证。现有模型路径、版本、线程数、ASR 复核条件、短词保护、尾静音、采样格式、依赖及命令集合均保留。未声称启用 NPU。

## 本次改动

1. `feature_demo/workers/voice.py`：停止监听后复用同一 worker 已加载的引擎，每次重新打开与关闭麦克风、重新校准，并再次设置本模块语法。跨模块不共享可变命令或回调。完整退出后 worker 可被释放，没有新增全局模型常驻缓存。
2. 监听异常时立即关闭该代麦克风并清除监听状态，允许重新开始；原先线程退出后仍显示监听中且麦克风保持打开。保留代次校验，旧识别结果仍不能派发新一轮动作。
3. 增加启动状态保护：取消校准之后，旧启动流程未结束前禁止再次启动，避免复用引擎时两个校准/清理流程互相干扰。
4. `feature_demo/workers/assistant.py`：LLM 加载与推理使用独立串行锁。加载模型时可立即中断并更新状态；同一个 llama 上下文的两个流不再并行执行。旧流关闭后才允许下一流进入，等待期间已过期的问题不再调用模型。保留旧回复、TTS 与播放的代次保护。
5. 独立审查发现并修复停止/重启竞态：监听线程退出之后，旧 `engine.stop()` 仍可能阻塞。新增活动停止计数，所有停止流程完成前拒绝重启，包括两个同时停止的情况；停止和线程等待仍在生命周期锁之外执行，不阻塞短时状态锁。

语音端点缩进修复（模拟 PCM 8 秒变 2.3 秒）属于已有部署，本次未改动端点，也没有把这项收益重复计入。

## 合成计时（Windows 本机）

解释器 `G:/codex/.venv/Scripts/python.exe`。使用真实 Worker 生命周期，外部模型用具备幂等 `load()` 的合成引擎代替：首次 load 固定等待 40 ms，PCM 是可关闭的阻塞替身。首次启动后停止，重复开始/停止 5 次，统计开始监听耗时中位数；校准和硬件驱动耗时未模拟。AI 加载中断另用固定等待 200 ms 的模型工厂，进入工厂后计时调用 `interrupt()`。

| 合成场景 | 改前 ms | 改后 ms |
| --- | ---: | ---: |
| 儿歌重复开启监听，中位数 n=5 | 40.476 | 0.175 |
| 机械臂语音重复开启监听，中位数 n=5 | 40.426 | 0.190 |
| AI 语音重复开启监听，中位数 n=5 | 40.458 | 0.210 |
| AI 模拟加载 200 ms 期间中断，单次 | 200.555 | 0.018 |

这些数值证明避免重复加载与移除控制锁阻塞的代码路径，不是 ASR 推理加速倍数。实际首次加载仍需相同模型开销，重新监听仍需麦克风打开和噪声校准；切换到新模块不承诺热启动。中断不会强制终止正在运行的底层加载/原生推理，旧工作返回后丢弃结果，下一问题等待同一模型上下文可用。

## 验证

尚未进行板端模型加载/重复监听计时、真实录音词错率/指令准确率、不同噪声条件、音频回声或实物动作验收。本地没有连接麦克风/机械臂，没有 SSH、部署或动作触发。曝光180及相机/UI文件未修改。
